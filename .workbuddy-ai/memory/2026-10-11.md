## RIDDIM hero — six-part polish pass (still uncommitted)

All on `riddim-zoom-story`, verified at 1440×900 in canvas units.

- **Opening frame.** The hero no longer opens fullscreen. Removed the
  `close: [0.08, 0.2]` phase from `riddim-choreography.ts`; `open` is now purely
  the opening ramp and `plane` is gated on the letterbox
  (`lens >= 0.9999 && open > 0.001`). `RIDDIM_PHASES` now begins
  `pullBack: [0.2, 0.42]`. At `p=0`: `open 0.0000`, `plane "off"`, `camS 2.5949`,
  `camDy 520.27` — the screen fills the viewport with the fascia above and the
  console below. Plane turns on at `p=0.85` (`open 0.3762`), inside the ramp, so
  no discontinuity. `data-plane="off"` at first paint.
- **First-paint camera** added to CSS so hydration causes no jump: no-JS machine
  box `{x:-23.4,y:-265.3,w:1486.9,h:2056.9}` vs live
  `{x:-22.8,y:-264.7,w:1485.6,h:2055.1}` (sub-pixel).
- **Console clearance.** `CONSOLE_DROP = 16` shifts `PAD_ROWS`, `CONSOLE_LABELS`,
  `LIVE_ROWS`, `PARAM_ROWS`, `KNOBS`, `FADER`, `LOOSE_LEDS`, `RIGHT_CAPS`,
  `LEFT_CAPS`; bottom screw 594→600 so the lit screen (ends 592) no longer cuts
  it. `text:VOLUME` bottom 631.0 vs screen bottom 592 → 39 units clear.
- **Title/counter gap.** `SCREEN_UI.title.size` 86→84 and `counter.x` 700→720 →
  gap 35.9 units (was 0.6).
- **Top-OLED nav.** New `SCREEN_NAV` in `riddim-content.ts` (PROJECTS
  `/projects`, BOOKMARKS `/bookmarks`, BLOG `/blog`), deliberately separate from
  `MACHINE_NAV`. Rendered by `ScreenNavRow` in `riddim-screen.tsx` as a sibling
  *after* `.screenRim`, so the wipe never covers it and it never duplicates on
  the plane. Non-interactive path keeps `data-screen-nav` on the print span
  (required by the server-render test). All three hit-test `clickable: true`.
- **Type opacity in the LCD only.** `.title` 0.84, `.role` 0.62.
- **Performance.** Root finding: writing a custom property on `.hero`
  invalidates the whole subtree regardless of what reads it, and cost scales with
  subtree size (1613 ms vs 166 ms on `.plane`; an *unused* property cost 1588 ms).
  `display: none` subtrees are not skipped, `content-visibility: hidden` ones are
  (10× cheaper). Added:
  `.hero:not([data-plane='on']) .plane { visibility: hidden; content-visibility: hidden; }`
  and `.hero[data-plane='on'] .screen { content-visibility: hidden; }`.
  Pointer ticker now starts on demand and stops when settled; datasets written
  only on flip. Recalc over a full scroll pass 444→261–288 ms, task
  1072→723–765 ms. Holds 60 fps: median 16.7 ms, p95 18.2 ms, 6/260 frames > 20 ms.
  Negative results kept honest: LED `blur(5px)`→gradient saves only 1.6%; sheen,
  machine box-shadow and pad-pulse measured within noise; no speculative
  `contain:` added.
- New `.boot` cue (`SCROLL TO POWER UP ↓`) in the band between module lip and
  console at `top: calc(50% + 100cqw * 134 / 922 + 3px)`, fading with
  `--r-power`.

Green: `tsc --noEmit` clean, `eslint features/landing-page/components/riddim-hero`
clean, jest **7 suites / 110 tests passing**. Not yet verified: the < 769px stack
layout, and the flip handoff to the About section.
